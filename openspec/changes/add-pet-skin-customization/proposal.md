## Why

当前桌宠运行时只有一套固定角色资产，用户无法在保持桌宠主体验的同时选择自己喜欢的外观。皮肤选择是桌宠个性化的最小可用入口；本变更准备三套可验证的官方皮肤资源，但首次启动只提供 `simple-cloud`，其他皮肤通过插件目录按需安装，避免扩大默认运行时资源负担。

本次首发皮肤方向来自 `references/github-skin-research/` 中的参考预览：简洁云朵、橙色小龙和三花猫。其中简洁云朵作为默认皮肤，使用 `rullerzhou-afk/clawd-on-desk` 固定提交中的 Cloudling 待机首帧；项目所有者已确认取得权利人授权，具体来源和发布依据记录在 `src-tauri/assets/README.md`。橙色小龙和三花猫继续使用项目自有原创资产，其他参考仓库素材不进入发布包。

## What Changes

- 准备三套官方皮肤包：简洁云朵、橙色小龙、三花猫；首次安装和无法恢复有效偏好时只安装并启用简洁云朵。
- 在插件目录中展示其他官方皮肤的缩略预览和中文名称；现有快捷面板的设置入口只展示已安装且启用的皮肤。
- 支持用户点击皮肤预览后立即切换桌宠外观；切换期间保留桌宠位置、大小、透明命中和待机动画行为。
- 将当前皮肤标识保存到本地版本化偏好，应用重启后恢复；偏好缺失、损坏、未知版本或未知皮肤标识时回退到简洁云朵。
- 为皮肤资产建立 manifest 和统一资源约定，描述透明 RGBA、基准尺寸、帧生成方式、缩略图和显示名称，避免每套皮肤各自实现加载逻辑。
- 皮肤切换或资源加载失败时保留上一套可用皮肤；如果启动时没有可用的已选皮肤，则使用简洁云朵并保持桌宠、托盘和统计采集可用。
- 补充皮肤选择、持久化、重启恢复、故障回退、DPI/大小兼容和 Windows 手工验证。

## Capabilities

### New Capabilities

- `pet-skin-customization`: 提供官方皮肤包的资源校验、已安装皮肤清单、预览、选择、实时应用、本地持久化和资源故障回退。

### Modified Capabilities

无。快捷面板和桌宠大小设置的既有行为保持不变；本能力只增加设置视图中的皮肤选择，并要求切换时兼容已有桌宠窗口约束。

## Impact

- Rust 桌宠窗口和帧生成：把当前单一 `include_bytes!` 资源改为按 manifest 选择源图，并在切换时重建帧、透明命中图和窗口尺寸。
- Tauri 命令与本地偏好：新增读取皮肤清单、读取当前皮肤、选择皮肤和持久化皮肤标识的接口；偏好只保存版本、皮肤 ID 及必要的完整性校验信息。
- Svelte/TypeScript 快捷面板设置视图：新增中文皮肤画廊、预览状态、加载/保存失败反馈和键盘可操作状态。
- 资源目录与构建：准备三套透明 PNG 或等价位图资源、缩略图和 manifest 校验；仅将简洁云朵随核心安装，橙色小龙和三花猫以本地官方插件包或目录包源提供；不引入远程资源或在线下载。
- 测试与验证：覆盖 manifest 校验、默认值、选择和持久化、损坏配置回退、切换失败回退，以及桌宠大小、DPI、位置和快捷面板兼容性。

## Non-Goals

- 不支持用户上传任意图片、在线皮肤商店、网络下载、账号、云同步或社区分享。
- 不在本次变更中引入 Live2D、骨骼动画、逐皮肤独立动画编辑器或任意主题颜色编辑。
- 不改变软件使用统计的采集口径、数据库结构、隐私边界或完整统计页。
- 不把 GitHub 参考项目中的第三方角色或受限许可证素材直接复制到发布包中；已获权利人授权并在资源说明中记录的 Cloudling 素材除外。

## Privacy Impact

皮肤功能只在本地保存一个非敏感的皮肤 ID 及版本信息，不记录预览次数、选择历史、桌面内容或用户行为轨迹。切换皮肤不新增网络请求、遥测、窗口标题、文档名、键盘内容、截图或鼠标轨迹；统计采集继续沿用现有本地实现和权限边界。
