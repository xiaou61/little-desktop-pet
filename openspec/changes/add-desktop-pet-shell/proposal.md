## 为什么

当前应用启动后直接展示普通统计窗口，用户看到的是使用统计器，而不是桌宠。产品必须把可见、可拖动、常驻桌面的角色设为主体验，并把已有的每日软件使用统计降为桌宠提供的附属面板。

## 变更内容

- 增加一个透明、无边框、始终置顶、跳过任务栏的 Windows 桌宠窗口，正常启动时首先显示桌宠。
- 桌宠使用 Rust 原生分层窗口渲染，不为桌宠本体常驻 WebView；统计面板仍按需使用现有 Svelte WebView。
- 提供一个可替换的原创圆形机器人角色资产，并增加低频呼吸/轻微浮动待机效果。
- 支持拖动桌宠、保存位置、在显示器工作区内恢复位置，并让角色透明区域不拦截桌面点击。
- 单击桌宠打开或关闭其下方的快捷面板；用户可从快捷面板进入每日使用统计，关闭面板后桌宠继续存在，后台采集不中断。
- 托盘菜单改为“显示/隐藏桌宠”“打开使用统计”“退出”；重复启动应用时显示并聚焦已有桌宠。
- 将产品名、窗口标题和托盘提示从“每日应用使用”调整为“小桌宠”，使统计面板成为次级功能。

## 非目标

- AI 对话、语音、提醒、待办、情绪或养成系统。
- 多角色、皮肤商店、角色编辑器或从网络下载资源。
- 复杂骨骼动画、Live2D、物理碰撞、自动行走或跨屏自主移动。
- 点击穿透开关、开机自启和更多统计维度；这些可以后续独立增加。
- 修改现有软件使用数据的采集口径、SQLite schema 或隐私边界。

## 能力

### 新增能力

- `desktop-pet-shell`：提供原生透明桌宠窗口、桌面交互、位置恢复、托盘控制，以及进入每日使用统计面板的入口。

### 修改能力

无。

## 隐私影响

桌宠窗口只处理自身角色像素、鼠标拖动/单击和窗口位置，不读取桌面内容。持久化内容只新增桌宠窗口坐标；不会新增遥测、网络请求、输入内容、截图或窗口标题采集。

## 影响范围

- 调整 Tauri 生命周期：应用启动后创建桌宠，而不是直接打开统计面板。
- 在 Rust 中新增 Windows 分层窗口、透明像素命中测试、拖动、显示器工作区约束和位置保存模块。
- 新增一个打包进可执行文件的透明 PNG 角色资产，以及低频原生待机渲染。
- 修改托盘菜单、单实例行为、产品名称和面板打开方式。
- 保留现有采集器、SQLite 数据和统计面板业务逻辑。
