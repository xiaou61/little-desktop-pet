## Purpose

让应用首先表现为一个轻量、可见、可拖动的 Windows 桌宠，并通过桌宠提供每日软件使用统计入口，而不是把普通统计窗口当作产品主界面。

## ADDED Requirements

### Requirement: 桌宠作为启动后的主体验
系统 SHALL 在正常启动后显示桌宠窗口，并 MUST NOT 自动打开每日使用统计面板。

#### Scenario: 第一次启动应用
- **GIVEN** 当前 Windows 用户会话中没有正在运行的小桌宠实例
- **WHEN** 用户启动应用
- **THEN** 系统启动唯一的后台采集器和托盘图标
- **AND** 显示桌宠窗口
- **AND** 不自动显示统计面板

#### Scenario: 重复启动应用
- **GIVEN** 小桌宠已经在当前 Windows 用户会话中运行
- **WHEN** 用户再次启动应用
- **THEN** 系统不创建第二个采集器或桌宠
- **AND** 显示已有桌宠并把它带回可见区域

### Requirement: 提供真正的透明桌宠窗口
桌宠 SHALL 显示在无边框、无阴影、始终置顶且不出现在任务栏的透明窗口中；角色以外的透明像素 MUST 不遮挡桌面，也 MUST 不拦截鼠标操作。

#### Scenario: 桌宠显示在桌面上
- **GIVEN** 桌宠处于显示状态
- **WHEN** 用户查看桌面或切换普通应用窗口
- **THEN** 只能看到角色像素，不出现矩形背景、标题栏、边框或系统阴影
- **AND** 桌宠保持在普通应用窗口之上
- **AND** Windows 任务栏中不显示独立桌宠按钮

#### Scenario: 点击角色外的透明区域
- **GIVEN** 鼠标位于桌宠窗口矩形内但对应角色像素完全透明
- **WHEN** 用户点击或拖动
- **THEN** 输入传递给该位置下方的桌面或应用窗口

#### Scenario: 点击角色可见区域
- **GIVEN** 鼠标位于具有可见不透明度的角色像素上
- **WHEN** 用户按下鼠标
- **THEN** 桌宠接收该次交互

### Requirement: 显示本地角色和轻量待机状态
系统 SHALL 使用随应用打包的原创角色资产，并 SHALL 在桌宠可见且未拖动时展示低频、循环的呼吸或轻微浮动待机效果。

#### Scenario: 离线显示桌宠
- **GIVEN** 计算机没有网络连接
- **WHEN** 应用启动并显示桌宠
- **THEN** 角色资产和待机效果仍然完整可用
- **AND** 系统不请求远程图片、字体或动画资源

#### Scenario: 桌宠处于待机状态
- **GIVEN** 桌宠可见且用户没有拖动角色
- **WHEN** 待机动画循环
- **THEN** 角色进行幅度克制的呼吸或浮动变化
- **AND** 窗口布局和角色可点击区域保持稳定

#### Scenario: 角色资产无法载入
- **GIVEN** 打包角色资产缺失或无法解码
- **WHEN** 桌宠初始化
- **THEN** 后台采集器和托盘仍然可用
- **AND** 系统不会显示一个不可交互的透明拦截窗口

### Requirement: 支持单击和拖动两种交互
系统 SHALL 把角色可见区域上的短单击解释为打开桌宠下方的快捷面板，把超过移动阈值的按住移动解释为拖动，并 MUST NOT 在一次拖动结束时同时打开快捷面板。

#### Scenario: 单击桌宠
- **GIVEN** 桌宠可见且快捷面板尚未打开
- **WHEN** 用户在角色可见区域按下并释放鼠标，移动距离没有超过拖动阈值
- **THEN** 系统在桌宠下方打开快捷面板
- **AND** 桌宠继续显示

#### Scenario: 快捷面板已经打开时单击桌宠
- **GIVEN** 快捷面板已经存在
- **WHEN** 用户单击桌宠
- **THEN** 系统关闭已有快捷面板
- **AND** 不创建第二个面板

#### Scenario: 拖动桌宠
- **GIVEN** 桌宠可见
- **WHEN** 用户在角色可见区域按住并移动超过拖动阈值
- **THEN** 桌宠跟随指针移动
- **AND** 拖动结束后保持在显示器工作区内
- **AND** 这次交互不打开快捷面板

### Requirement: 恢复并修正桌宠位置
系统 SHALL 在本地保存最近一次拖动结束位置，在下次启动时恢复；如果保存位置不再属于任何可用显示器工作区，系统 SHALL 把桌宠放到主显示器工作区右下角并保留安全边距。

#### Scenario: 恢复有效位置
- **GIVEN** 上次退出前保存的位置仍位于一个可用显示器工作区内
- **WHEN** 应用再次启动
- **THEN** 桌宠在该位置显示

#### Scenario: 显示器布局已经变化
- **GIVEN** 保存位置因为显示器断开、分辨率变化或缩放变化而落在所有工作区之外
- **WHEN** 应用启动或显示桌宠
- **THEN** 桌宠移动到主显示器工作区右下角
- **AND** 角色完整保持在可见工作区内

#### Scenario: 拖动接近工作区边缘
- **GIVEN** 用户正在拖动桌宠
- **WHEN** 指针移动会让角色完全离开当前显示器工作区
- **THEN** 系统限制最终位置，至少让完整角色保持可见

### Requirement: 通过托盘控制桌宠和统计面板
系统 SHALL 提供简体中文托盘菜单，包含“显示/隐藏桌宠”“打开使用统计”和“退出”，并 SHALL 让统计面板关闭与应用退出保持不同语义。

#### Scenario: 从托盘隐藏和显示桌宠
- **GIVEN** 应用正在运行
- **WHEN** 用户选择“隐藏桌宠”
- **THEN** 桌宠窗口不可见但后台采集继续
- **AND** 菜单操作变为“显示桌宠”
- **WHEN** 用户随后选择“显示桌宠”
- **THEN** 桌宠在有效工作区位置重新显示

#### Scenario: 从托盘打开统计
- **GIVEN** 应用正在运行，无论桌宠是否可见
- **WHEN** 用户选择“打开使用统计”
- **THEN** 系统打开或聚焦唯一的统计面板

#### Scenario: 关闭统计面板
- **GIVEN** 统计面板和桌宠都可见
- **WHEN** 用户关闭统计面板
- **THEN** 统计面板被销毁
- **AND** 桌宠、托盘和后台采集继续运行

#### Scenario: 从托盘退出
- **GIVEN** 应用正在运行
- **WHEN** 用户选择“退出”
- **THEN** 系统保存待写入统计和桌宠位置
- **AND** 关闭桌宠、统计面板、托盘和后台采集器

### Requirement: 保持桌宠后台资源轻量
统计面板关闭且桌宠待机动画运行时，系统 SHALL 在 Windows 参考环境保持平均 CPU 占用低于 1%，并 SHALL 使主进程私有工作集不超过 50 MiB。

#### Scenario: 测量桌宠稳定待机资源
- **GIVEN** Windows 11 x64 参考机器、release 构建、统计面板已关闭、桌宠可见且完成两分钟初始化
- **WHEN** 在接下来五分钟测量主进程 CPU 和私有工作集
- **THEN** 平均 CPU 占用低于 1%
- **AND** 私有工作集不超过 50 MiB

### Requirement: 不扩大隐私采集范围
桌宠 shell MUST 只处理角色渲染、角色交互和窗口位置，不得新增桌面内容、窗口内容或用户输入记录。

#### Scenario: 用户与桌宠交互
- **GIVEN** 用户单击、拖动、隐藏或显示桌宠
- **WHEN** 系统处理这些操作
- **THEN** 持久化内容最多包含桌宠窗口坐标和已有软件使用汇总
- **AND** 不保存鼠标轨迹、桌面截图、窗口标题或新的输入内容
