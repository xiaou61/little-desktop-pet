## Purpose

提供一个私密、低资源的本地统计能力，让 Windows 用户按本地日期查看活跃电脑时间分布；该能力通过桌宠入口使用，不取代桌宠主界面。

## ADDED Requirements

### Requirement: 统计前台软件活跃时长
采集器运行时，系统 SHALL 将经过的时间归属给至多一个可识别的前台软件，并 MUST 排除桌宠和采集器自身进程。

#### Scenario: 活跃软件获得时长
- **GIVEN** 采集器正在运行、用户处于活跃状态、且一个可识别软件位于前台
- **WHEN** 一个测量区间结束且没有发生排除状态
- **THEN** 系统把该区间增加到软件在当前本地日期的总时长
- **AND** 同一个区间不能同时增加到其他软件

#### Scenario: 无法识别前台软件
- **GIVEN** 前台进程受保护、已经退出，或无法解析为软件身份
- **WHEN** 一个测量区间结束
- **THEN** 系统不为该区间记录软件时长
- **AND** 继续处理之后的测量区间

#### Scenario: 统计面板位于前台
- **GIVEN** 统计面板是当前前台窗口
- **WHEN** 一个测量区间结束
- **THEN** 系统不把该区间增加到任何软件的每日时长

### Requirement: 排除空闲和不可用时段
系统 SHALL 在 Windows 报告用户连续五分钟没有输入后停止归属软件时长，并 MUST 排除锁屏和系统挂起期间。

#### Scenario: 达到空闲阈值
- **GIVEN** 可识别软件保持前台且 Windows 会话未锁定
- **WHEN** 距离上次用户输入达到五分钟
- **THEN** 系统停止继续增加该软件时长
- **AND** 保留阈值之前已经累计的时长

#### Scenario: 空闲后恢复活动
- **GIVEN** 采集因为达到输入阈值而处于空闲暂停状态
- **WHEN** Windows 报告新的用户输入且有可识别软件位于前台
- **THEN** 系统从下一个测量区间恢复统计
- **AND** 不补记空闲期间

#### Scenario: Windows 会话锁定
- **GIVEN** 采集器运行时用户锁定 Windows 会话
- **WHEN** 会话保持锁定
- **THEN** 锁定期间不能归属给任何软件

#### Scenario: 系统挂起
- **GIVEN** 采集器运行时 Windows 让机器进入挂起
- **WHEN** 进程在恢复后继续运行
- **THEN** 挂起期间不能归属给任何软件
- **AND** 后续测量无需人工恢复即可继续

### Requirement: 使用单调时长和稳定的本地日期
系统 SHALL 使用单调时钟测量时长，使用 UTC 保存时间戳，并按照采集时 Windows 生效的本地日历日期归属汇总。

#### Scenario: 活动跨越本地午夜
- **GIVEN** 软件在本地午夜前后持续位于前台
- **WHEN** 一个测量区间跨过午夜
- **THEN** 午夜前的部分归属到前一天
- **AND** 午夜后的部分归属到新的一天

#### Scenario: 系统时钟发生变化
- **GIVEN** 采集器运行时 Windows 修改了墙上时钟或时区
- **WHEN** 系统继续测量活动
- **THEN** 归属时长反映单调时钟经过的真实时长，而不是墙上时钟差值
- **AND** 已保存的每日汇总仍保持原来的采集日期

#### Scenario: 出现异常长测量间隔
- **GIVEN** 采集器有一段足以让前台状态不确定的时间没有采样
- **WHEN** 测量恢复
- **THEN** 不把这段不确定间隔归属给任何软件

### Requirement: 持久化和恢复每日汇总
系统 SHALL 将软件元数据和每日使用汇总保存到本地 SQLite，每 30 秒至少保存一次，并在正常退出时保存待写入内容。

#### Scenario: 周期性保存
- **GIVEN** 采集器内存中有尚未保存的活动
- **WHEN** 距离上一次成功保存已达到 30 秒
- **THEN** 系统在一个数据库事务中提交软件元数据和每日时长

#### Scenario: 正常退出
- **GIVEN** 采集器内存中有尚未保存的活动
- **WHEN** 用户从托盘选择退出
- **THEN** 系统在终止前尝试执行最后一次数据库事务

#### Scenario: 异常终止
- **GIVEN** 上一次成功保存发生在 30 秒以内
- **WHEN** 进程异常终止并在之后重新启动
- **THEN** 已提交的汇总仍然可以读取
- **AND** 丢失的数据不超过上次保存之后的测量内容
- **AND** 不补记进程停止期间的软件时长

#### Scenario: 无法持久化
- **GIVEN** 本地数据库无法打开或写入
- **WHEN** 采集器初始化或保存活动
- **THEN** 系统显示错误状态
- **AND** 不声称受影响的活动已经保存
- **AND** 保持响应，以便用户可以退出

### Requirement: 展示每日软件使用情况
系统 SHALL 提供简体中文统计面板，展示今天或选中历史日期的记录状态、总活跃时长，以及每个软件的显示名、可执行文件名回退、时长和占比。

#### Scenario: 打开今天的面板
- **GIVEN** 用户从快捷面板的完整统计入口或托盘打开统计面板
- **WHEN** 当前本地日期存在使用记录
- **THEN** 面板默认选择今天
- **AND** 显示每日总活跃时长和记录状态
- **AND** 软件按时长降序排列，同时时长相同按名称排序

#### Scenario: 选择历史日期
- **GIVEN** 历史本地日期存在已保存的使用记录
- **WHEN** 用户切换到该日期
- **THEN** 面板只展示该日期的总时长、软件行和占比
- **AND** 不允许向今天之后的日期前进

#### Scenario: 选中日期没有记录
- **GIVEN** 选中日期没有任何软件使用记录
- **WHEN** 面板展示该日期
- **THEN** 面板显示零总时长和明确的空状态
- **AND** 不生成虚假的软件行

#### Scenario: 内存活动尚未保存
- **GIVEN** 选中日期同时存在已提交数据和内存待写入数据
- **WHEN** 面板请求每日汇总
- **THEN** 展示的总时长和软件明细恰好合并两种来源一次

### Requirement: 作为单实例后台进程运行
系统 SHALL 在统计面板关闭时继续采集，SHALL 保证同一 Windows 用户会话只有一个采集实例，并 SHALL 只在用户明确退出或操作系统关机时终止。

#### Scenario: 首次正常启动
- **GIVEN** 当前 Windows 用户会话中没有正在运行的采集器
- **WHEN** 用户启动应用
- **THEN** 一个采集器和托盘图标启动
- **AND** 应用把用户带入桌宠主窗口，而不是直接进入统计面板

#### Scenario: 关闭统计面板
- **GIVEN** 统计面板打开且采集正在运行
- **WHEN** 用户关闭统计面板
- **THEN** 统计 WebView 被销毁
- **AND** 桌宠和后台采集继续运行

#### Scenario: 再次打开统计面板
- **GIVEN** 统计面板关闭期间采集仍然继续
- **WHEN** 用户从桌宠或托盘打开统计面板
- **THEN** 新面板展示最新的每日汇总
- **AND** 采集不会重复启动或重复计算

#### Scenario: 重复启动应用
- **GIVEN** 一个采集实例已经拥有当前 Windows 用户会话
- **WHEN** 用户再次启动可执行文件
- **THEN** 不启动第二个采集器或数据库写入者
- **AND** 已有实例打开或聚焦桌宠主窗口

#### Scenario: 用户从托盘退出
- **GIVEN** 采集器正在运行，无论统计面板是否打开
- **WHEN** 用户从托盘选择退出
- **THEN** 待写入数据按照正常退出要求处理
- **AND** 桌宠、采集器和托盘进程终止

### Requirement: 本地收集且保持最小化
系统 MUST 在没有账号和出站网络请求的情况下工作，并 SHALL 只收集软件身份元数据、本地日期、活跃时长以及持久化和状态展示所需的时间戳。

#### Scenario: 记录软件活动
- **GIVEN** 可识别的第三方软件位于前台
- **WHEN** 采集器记录它的活动
- **THEN** 持久化内容不包含窗口标题、文档名、网址、键盘内容、鼠标内容、截图或网络活动

#### Scenario: 设备没有网络
- **GIVEN** 计算机没有网络连接
- **WHEN** 用户继续使用软件并打开每日汇总
- **THEN** 所有范围内的功能仍然可用
- **AND** 系统不尝试遥测或同步

### Requirement: 满足后台资源预算
统计面板关闭时，系统 SHALL 在 Windows 参考环境的稳定采集阶段保持平均 CPU 占用低于 1%，且私有工作集不超过 50 MiB。

#### Scenario: 测量稳定阶段资源
- **GIVEN** Windows 11 x64 参考机器已经完成两分钟初始化、统计面板已销毁，且前台切换频率不超过每秒一次
- **WHEN** 在接下来五分钟测量进程 CPU 和私有工作集
- **THEN** 平均进程 CPU 占用低于 1%
- **AND** 私有工作集不超过 50 MiB
