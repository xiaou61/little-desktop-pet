## 为什么

当前桌宠单击后直接打开完整统计页，反馈过重，也让桌宠看起来像统计工具的启动器。需要一个紧贴桌宠出现的轻量快捷面板，让用户先看到今天的简短状态，再决定是否进入完整统计或调整桌宠外观。

## 变更内容

- 新增按需创建的桌宠快捷面板，默认显示在桌宠下方；空间不足时翻转到上方，并始终限制在当前显示器工作区内。
- 快捷面板采用 Windows Acrylic/Backdrop 玻璃材质和高不透明度半透明回退，提供轻微的透明度、模糊和缩放过渡，不使用全屏遮罩。
- 将桌宠短单击改为切换快捷面板：再次单击桌宠、点击面板外部或按 `Escape` 关闭；面板内部操作不会被误判为外部点击。
- 在快捷面板中展示今天的记录状态、总活跃时长和简短的软件使用概览，并提供“查看完整统计”和“设置”入口。
- 新增桌宠大小设置，默认 100%，允许以 10% 步进在 70%–160% 之间调整；调整立即作用于桌宠，重启后保留。
- 桌宠大小改变后重新计算窗口尺寸、命中区域和显示器边界约束，避免角色被裁切或移动到屏幕外。
- 保持托盘“打开使用统计”入口和现有统计采集口径不变；快捷面板关闭不影响桌宠或后台采集。

## 能力

### 新增能力

- `pet-quick-panel`：提供桌宠下方的玻璃材质快捷面板、今日概览、完整统计入口、设置入口，以及打开、关闭和定位行为。
- `pet-size-settings`：提供桌宠大小的范围、步进、实时应用、持久化和位置重新约束行为。

### 修改能力

无。现有桌宠窗口和每日软件使用统计的原有采集口径保持不变；本变更通过新增能力定义两者之间的交互集成。

## 非目标

- 不重做完整每日统计页，不新增图表、账号、云同步或网络服务。
- 不增加多角色、皮肤商店、自由缩放到任意百分比、Live2D 或复杂动画系统。
- 不改变前台软件、空闲、锁屏、挂起、跨日和本地 SQLite 的统计规则。
- 不在快捷面板中展示窗口标题、文档名、键盘内容、截图或其他新的隐私数据。

## 隐私影响

快捷面板只读取现有的本地每日汇总并在内存中保存短暂的打开状态。大小设置只新增本地偏好值（当前缩放百分比），不新增遥测、网络请求或用户行为明细；面板关闭后不保留其临时定位状态。

## 影响范围

- Tauri 生命周期和窗口控制：新增快捷面板的按需创建、聚焦、关闭、外部点击和 `Escape` 处理。
- Rust/Win32 桌宠适配层：暴露当前桌宠矩形和显示器工作区，支持按缩放比例重建帧并重新约束位置。
- Svelte/TypeScript 前端：实现中文快捷面板、今日概览、设置页或设置区，以及玻璃材质回退样式。
- 本地持久化：新增版本化桌宠偏好文件或等价 SQLite 设置记录，并覆盖损坏、缺失和超范围值的回退。
- 自动化测试和 Windows 手工验证：覆盖面板交互、定位翻转、缩放边界、重启恢复、DPI 和资源占用。
